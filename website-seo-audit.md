# Website SEO Audit Project

## Project Overview
This project demonstrates a basic SEO audit checklist for analyzing a website's on-page SEO.

## Audit Checklist

| SEO Element | What to Check | Recommendation |
|---|---|---|
| Title Tag | Is the title clear and relevant? | Write a unique title for each page. |
| Meta Description | Does it describe the page? | Write a relevant and engaging description. |
| H1 Heading | Is the main heading clear? | Use one clear main heading. |
| Images | Do images have alt text? | Add descriptive alt text where appropriate. |
| Internal Links | Are related pages linked? | Add useful internal links. |
| Mobile Friendly | Does the page work on mobile? | Test mobile usability. |

## Key Learning
This checklist helps identify possible on-page SEO improvements.

## Note
This is a sample audit checklist, not an audit of a verified live website.


## Real Website Audit: MagicBricks

**Website:** https://www.magicbricks.com/

### 1. Title Tag

**Current Title:** Real Estate | Property in India | Buy/Sale/Rent Properties | MagicBricks

**Status:** Needs Improvement

**Observation:** The title contains relevant real estate keywords but could be more concise.

**Recommendation:** Use a clear and concise title that describes the website's main services.
